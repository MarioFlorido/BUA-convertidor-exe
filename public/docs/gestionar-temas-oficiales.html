Gestionar temas oficiales

Cómo publicar, descargar y eliminar los temas que aparecen para todos los usuarios.

Antes de empezar: necesitas tener el proyecto descargado en tu Mac en la carpeta /Users/mario/BUA-convertidor-exe. Si no lo tienes, clónalo con git clone git@github.com:MarioFlorido/BUA-convertidor-exe.git y luego ejecuta npm install dentro de esa carpeta.

Abrir la herramienta

  1. Abre el Terminal (búscalo con ⌘ Espacio y escribe "Terminal").
  2. Navega a la carpeta del proyecto:
    cd /Users/mario/BUA-convertidor-exe
  3. Ejecuta la herramienta:
    npm run themes Aparecerá el menú. Elige la opción correspondiente.
1 · Publicar un tema nuevo
  1. En el menú, escribe 1 y pulsa Enter.
  2. Se abrirá el Finder para que selecciones el ZIP del tema. Localízalo y haz doble clic (o selecciona y pulsa Return).
  3. El script te pedirá el nombre visible del tema (el que verán los usuarios en el selector). Si el nombre entre corchetes ya está bien, pulsa Enter sin escribir nada.
  4. Te pedirá la actividad (ej: Doctorado, Grado) y una descripción corta. Ambos son opcionales — pulsa Enter para dejarlos en blanco.
  5. Cuando pregunte "¿Hacer commit y push ahora?", pulsa Enter (o escribe s) para publicarlo. En 1-2 minutos el tema estará visible para todos.
El nombre del archivo ZIP determina el ID interno del tema. Usa guiones bajos en lugar de espacios: Doctorado_27-28.zip ✓   Doctorado 27-28.zip ✗
2 · Descargar un tema existente
  1. En el menú, escribe 2 y pulsa Enter.
  2. Aparece la lista de temas. Escribe el número del que quieres y pulsa Enter.
  3. El script genera el ZIP y abre el Finder mostrando su ubicación. Desde ahí puedes copiarlo donde necesites.
3 · Eliminar un tema
  1. En el menú, escribe 3 y pulsa Enter.
  2. Aparece la lista de temas. Escribe el número del que quieres eliminar y pulsa Enter.
  3. El script pide confirmación. Escribe s y pulsa Enter para confirmar. Esta acción no se puede deshacer.
  4. Cuando pregunte si hacer push, pulsa Enter para confirmar. En 1-2 minutos el tema desaparecerá para todos los usuarios.
