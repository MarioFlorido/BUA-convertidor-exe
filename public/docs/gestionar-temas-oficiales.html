Gestionar estilos oficiales

Cómo publicar y eliminar los estilos que aparecen para todos los usuarios.

Antes de empezar: necesitas tener el proyecto descargado en la carpeta /Users/ruta/a/mi/copia/local. Si no lo tienes, clónalo con git clone git@github.com:MarioFlorido/BUA-convertidor-exe.git y luego ejecuta npm install dentro de esa carpeta.

Flujo general

flowchart TD
    Start([npm run publish-theme]) --> Pub[Proporcionar ruta al ZIP]
    Pub --> Extract[Extraer a public/themes/id/]
    Extract --> Config[Actualizar themes-config.json]
    Config --> Push[git commit + push]
    Push --> GH([GitHub Pages en 1-2 min])

    Start2([npm run unpublish-theme]) --> Del[Eliminar estilo oficial]
    Del --> Config2[Actualizar themes-config.json]
    Config2 --> Push2[git commit + push]
    Push2 --> GH

Publicar un estilo (oficial)

  1. Abre el Terminal (búscalo con ⌘ Espacio y escribe "Terminal").
  2. Navega a la carpeta del proyecto:
    cd /Users/mariofloridoperez/BUA-convertidor-exe
  3. Ejecuta el comando para publicar:
    npm run publish-theme -- /ruta/al/archivo/tema.zip Sustituye /ruta/al/archivo/tema.zip por la ruta real de tu archivo ZIP.
Publicar un estilo oficial
  1. En Terminal, desde la carpeta del proyecto, ejecuta:
    npm run publish-theme -- ~/Desktop/Doctorado_26-27.zip Sustituye la ruta con la ubicación real de tu ZIP.
  2. Opcionalmente, añade metadatos:
    npm run publish-theme -- ~/Desktop/Doctorado_26-27.zip --activity "Doctorado" --description "Estilo para Doctorado 26-27" Las opciones --activity y --description son opcionales.
  3. El script extrae el ZIP, lo valida y actualiza themes-config.json. Verás un mensaje indicando qué comandos ejecutar:
    git add public/themes/Doctorado_26-27/ public/themes-config.json
    git commit -m "feat(themes): publicar Doctorado_26-27"
    git push
  4. Ejecuta esos comandos. En 1-2 minutos el estilo estará visible en GitHub Pages para todos los usuarios.
Importante: El archivo debe ser un ZIP válido con dentro: config.xml y style.css (sin archivos de sistema como __MACOSX o .DS_Store). El nombre del ZIP (sin extensión) se convierte en el ID: Doctorado_26-27.zip → ID Doctorado_26-27.
Descargar un estilo oficial (para editar)

Los estilos oficiales se encuentran en public/themes/. Puedes descargarlos como ZIP desde GitHub directamente:

  1. Abre el repositorio en GitHub
  2. Selecciona la carpeta del estilo que quieres (ej: Doctorado_26-27)
  3. Haz clic en el botón ⬇ Code y luego Download ZIP

Alternativa desde Terminal: Los estilos ya están en tu copia local en public/themes/<id>/. Puedes comprimirlos con:

zip -r Doctorado_26-27.zip public/themes/Doctorado_26-27/
Eliminar un estilo oficial
  1. En Terminal, ejecuta:
    npm run unpublish-theme
  2. Te mostrará una lista de estilos oficiales. Introduce el nombre del que quieres eliminar (debe coincidir exactamente, ej: Doctorado_26-27)
  3. El script pide confirmación. Escribe s y pulsa Enter. Esta acción no se puede deshacer.
  4. El script te mostrará los comandos git para hacer commit y push:
    git add public/themes-config.json
    git commit -m "feat(themes): eliminar Doctorado_26-27"
    git push
  5. Ejecuta esos comandos. En 1-2 minutos el estilo desaparecerá para todos los usuarios.
Nota: El directorio public/themes/<id>/ se elimina del repositorio, pero puedes recuperarlo desde el historial de git si es necesario.
