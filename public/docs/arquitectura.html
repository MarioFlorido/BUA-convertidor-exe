Flujo del wizard (usuario)

Pasos que sigue el usuario para convertir un documento.

flowchart LR
    A([Subir DOCX]) --> B[Parsear con Mammoth]
    B --> C[Configurar estructura]
    C --> D[Seleccionar estilo]
    D --> E[Convertir]
    E --> F([Descargar ELPX / PDF])

Pipeline interno de conversión

El SemanticDocument es el núcleo del sistema: un modelo agnóstico al formato de salida. Los renderers ELPX y PDF son independientes entre sí; añadir un nuevo formato es escribir un renderer adicional sin tocar lo demás. 

flowchart TD
    DOCX([DOCX]) --> Parser[DocxParser / Mammoth.js]
    Parser --> HTML[HTML intermedio]
    HTML --> Struct[parseDocumentStructure]
    HTML --> Builder[SemanticBuilder]
    Struct --> Builder
    Builder --> SemDoc([SemanticDocument])
    SemDoc --> ELPX[ElpxRenderer / .elpx]
    SemDoc --> PDF[PrintHtmlRenderer / PDF]

Sistema de estilos

Dos fuentes de estilos convergen en el ThemeRegistry, la fuente de verdad única de la aplicación. 

flowchart TD
    subgraph Oficiales[Estilos oficiales - todos los usuarios]
        Repo[public/themes/id/ - en git] -->|pack-themes| ZIP[id.zip - generado]
        ZIP -->|fetch al arrancar| BIP[BuiltInThemeProvider]
    end
    subgraph Locales[Estilos locales - solo este navegador]
        Upload[ZIP subido por el usuario] --> IDB[IndexedDB]
        IDB --> UTP[UserThemeProvider]
    end
    BIP --> Reg[ThemeRegistry]
    UTP --> Reg
    Reg --> Sel[Selector de estilos]
TipoVive enVisible paraGestión

Oficiales public/themes/<id>/ + themes-config.json Todos npm run themes
Locales IndexedDB del navegador Solo ese usuario UI «Importar estilo local»

Secuencia de arranque

Al cargar la app, ThemeBoot orquesta la carga de ambas fuentes de estilos antes de habilitar la UI. 

sequenceDiagram
    participant App
    participant ThemeBoot
    participant BuiltIn as BuiltInThemeProvider
    participant User as UserThemeProvider
    participant Registry as ThemeRegistry

    App->>ThemeBoot: bootThemeSystem()
    ThemeBoot->>User: init() IndexedDB
    ThemeBoot->>BuiltIn: loadAll()
    BuiltIn-->>Registry: register(estilos oficiales)
    ThemeBoot->>User: loadAll()
    User-->>Registry: register(estilos locales)
    ThemeBoot-->>App: activeThemeId, themeCount
