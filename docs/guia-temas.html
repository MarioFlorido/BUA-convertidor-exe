Guía de uso

Cargar y gestionar estilos

Cómo importar plantillas visuales para tus exportaciones a eXeLearning y PDF, cómo cambiarlas y cómo eliminarlas.

Flujo de conversión

Los estilos se aplican en el paso 3 del proceso de conversión.

flowchart LR
    A([Subir DOCX]) --> B[Parsear con Mammoth]
    B --> C[Configurar estructura]
    C --> D[Seleccionar estilo]
    D --> E[Convertir]
    E --> F([Descargar ELPX / PDF])

¿Qué es un estilo?

Un estilo es una plantilla visual que define la apariencia del recurso final: colores, tipografías, logos, iconos, portada y estilos para títulos, párrafos, listas, cajas de definición/ejemplo/etc.

El convertidor aplica el estilo activo cuando exportas a eXeLearning (.elpx) o a PDF.

Tipos de estilo

Tipo Dónde vive Quién lo ve Se puede borrar
Oficial Base Servidor de la aplicación Todos los usuarios No (es fijo)
Local Tu navegador (almacenamiento local) Solo tú, en este navegador Sí
Importante: los estilos que tú importas son locales a este navegador. Si abres la aplicación en otro navegador o en otro ordenador, esos estilos no estarán ahí. Esto es totalmente esperado.

Cómo importar un estilo

  1. Ve al panel "Importar estilo local".
  2. Arrastra el archivo ZIP del estilo al recuadro, o haz clic en él para abrir el selector de archivos.
  3. La aplicación valida el ZIP. Si todo está bien, el estilo aparece inmediatamente en la lista marcado como Local.
  4. Para usarlo: en el conversor, cuando elijas el estilo, selecciónalo en la lista.

Qué debe contener el ZIP

El archivo ZIP debe incluir al menos estos archivos en su raíz:

MiTema_27-28.zip
├── config.xml         ← obligatorio (metadatos del estilo)
├── style.css          ← obligatorio (estilos visuales)
├── screenshots.png    ← opcional pero recomendado (miniatura)
├── fonts/             ← tipografías del estilo
├── icons/             ← iconos para las cajas semánticas
└── img/               ← imágenes (logos, portada, etc.)

El nombre del archivo importa

El nombre del ZIP (sin extensión) se convierte en el identificador del estilo. Por ejemplo:

  • Doctorado_27-28.zip → identificador Doctorado_27-28
  • Master_Bibliotecas.zip → identificador Master_Bibliotecas

Recomendación: usa guiones bajos (_) en lugar de espacios, y evita acentos y caracteres especiales en el nombre del archivo.

Recomendaciones para la miniatura

Incluye screenshots.png (o screenshot.png) en la raíz del ZIP. Se mostrará como miniatura en el selector de estilos. Tamaño recomendado: 1200×500 px (banner apaisado mostrando la portada o cabecera del estilo).

Cómo cambiar entre estilos

Cuando hayas importado tus estilos, cuando vayas a generar el recurso (exportar a ELPX o PDF), la aplicación te mostrará la lista de estilos disponibles. Solo tienes que seleccionar el que quieras y continuar.

Cómo eliminar un estilo

  1. Localiza el estilo en la lista de "Estilos disponibles".
  2. Haz clic en el botón Eliminar a la derecha de su nombre.
  3. Confirma la operación en el diálogo.
Atención: al eliminar un estilo local se borra definitivamente de este navegador. Si quieres volver a tenerlo, deberás importarlo de nuevo desde el archivo ZIP original. El estilo Base no se puede eliminar.

Volver a usar un estilo borrado

Guarda siempre una copia del archivo ZIP fuera de la aplicación (por ejemplo en tu carpeta de trabajo). Si borras el estilo y quieres recuperarlo, basta con importarlo de nuevo.

Preguntas frecuentes

¿Mis compañeros verán mis estilos?

No. Los estilos que tú importas viven en el almacenamiento de tu navegador. Para que los demás los usen, cada uno debe importar el mismo archivo ZIP.

¿Qué pasa si limpio la caché del navegador?

Si limpias el almacenamiento local del navegador (no la simple caché de páginas, sino "Datos del sitio" / "IndexedDB"), tus estilos locales se perderán. Conserva siempre los ZIPs originales.

El idioma del estilo sale incorrecto en la interfaz

La aplicación lee el idioma del archivo config.xml dentro del estilo, en la etiqueta: 

<language>es</language>

Valores aceptados: es (español), ca (catalán/valenciano), en (inglés). Si la etiqueta falta o tiene otro valor, se asume español por defecto.

El estilo no muestra miniatura

Comprueba que el ZIP contenga un archivo screenshots.png (o screenshot.png) en la raíz. Si no lo tiene, el estilo funcionará igual pero sin miniatura.

¿Puedo subir un estilo mal formado?

La aplicación valida los archivos mínimos (config.xml y style.css). Si faltan, verás un mensaje de error y el estilo no se importará. Sin embargo, no se valida el contenido CSS: un CSS erróneo puede producir resultados visuales inesperados sin ser bloqueado.
