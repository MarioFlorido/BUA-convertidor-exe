BUA ConvertidoreXe — Interfaz, colores, tipografía y estructura visual

Resumen ejecutivo

BUA ConvertidoreXe adopta un diseño minimalista funcional con énfasis en la claridad y la accesibilidad. La interfaz prioriza el contenido y las acciones del usuario, eliminando elementos decorativos. El sistema de colores es institucional (azul profesional + escala de grises), las sombras son sutiles, y la tipografía utiliza fuentes del sistema para máxima compatibilidad y legibilidad.

Filosofía de diseño

Minimalismo

  • Sin ornamentación. Cada elemento tiene un propósito funcional.
  • Mucho espacio en blanco. Respira el contenido; máximo ancho de contenedor: 900px.
  • Jerarquía clara. Tamaños de tipo, colores y espacio guían la atención.
  • Transiciones suaves. Animaciones rápidas (0.12–0.2s) para feedback inmediato sin distracción.

Accesibilidad e inclusión

  • Contraste alto. Ratio WCAG AA+ en todos los textos.
  • Fuentes del sistema. Ninguna descarga externa; máxima compatibilidad y velocidad.
  • Estados visuales claros. Hover, active, disabled, error tienen sus propias señales.
  • Responsive. Diseño fluido desde 320px (mobile) hasta 1400px (desktop).

Observación sobre el palette

El palette de la interfaz es fundamentalmente Blue + escala de grises.

  • Azul (#1B6EC2): Color primario de la interfaz. Aparece en todos lados: botones de acción, links, paso activo, hovers, focus rings. Es el color omnipresente.
  • Escala de grises: Textos (3 pesos), bordes, fondos, superficies. Todo lo demás gira en torno a esta escala.
  • Green (#34C759) y Red (#D92B2B): Acentos puntuales y muy poco frecuentes. Aparecen solo en: icono de éxito (checkmark verde), textos de error (rojo), bordes de campos inválidos, alerts de error/success. Nunca en la UI principal.

En resumen: Es un palette muy contenido. Si el 95% de lo que ves es azul + grises, el 5% restante (rojo/verde) lo uses solo para feedback inmediato de errores o confirmaciones de usuario.

Estados de interacción

Hover

  • Botones azules: cambio de color a #155FAF + elevación vertical (-1px).
  • Cards y items: borde-ligero toma color azul, sombra aumenta a shadow-sm.
  • Links de ayuda: color azul + subrayado.

Focus (para accesibilidad de teclado)

  • Inputs: borde azul + ring de 3px en azul light.
  • Botones: box-shadow azul.

Disabled

  • Botones: opacidad 0.7, texto gris, sin cursor (not-allowed).
  • Inputs: fondo gris light, texto gris claro, cursor not-allowed.

Error/invalid

  • Bordes rojo tenue (rgba(217,43,43,.4)).
  • Mensaje en rojo debajo del campo.
  • No hay borde de acento a la izquierda.

Detalles notables

Border radius

  • --radius-sm: 6px — botones, inputs pequeños.
  • --radius: 10px — cards, modales.
  • --radius-lg: 14px — upload zone, grandes contenedores.

Transiciones

Todas las animaciones duran 0.12s a 0.2s para feedback rápido sin sentirse artificial. Solo propiedades: all, color, box-shadow, border-color, background, transform.

Iconografía

SVGs inline sin descarga. Colores heredados del texto o contexto (azul primario para acciones). Tamaños: 14–56px según uso (pequeño: meta; grande: hero).

Responsive

  • ≤640px: Header reduce altura a 52px, oculta subtítulos. Step bar scroll horizontal. Container padding 1.5rem × 1.25rem. Grids a 1 columna.
  • 641–1024px: Layout fluido. Grids: 2 columnas.
  • ≥1025px: Grids: 3–4 columnas, máxima anchura 900px.

Velocidad de carga

  • Fuentes nativas (no externos).
  • Iconos SVG inline (no sprites ni iconfonts).
  • CSS minificado sin preprocesadores (puro CSS3 con variables).
  • Sin web fonts o librerías CSS (p. ej., Bootstrap, Tailwind).
